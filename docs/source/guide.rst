Choose a workflow
=================

Start with a fiber workflow, then inspect fields and effective indices before
computing coupling or propagation. The inverse taper ratio describes transverse
scaling; it is not a longitudinal distance. Define a taper profile when relating
modal results to a physical propagation length.
